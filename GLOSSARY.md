# Brevi

Brevi lets users upload source videos and generate playable videos from them.

## Language

**Project**:
A library item owned by one user. It has one Original and can have zero or more Exports.

**Original**:
The source video a user uploads for a Project. A different Original starts a new Project.

**Export**:
A playable video generated from a Project's Original. The first milestone generates a full-length Export.

**Highlight Clip**:
A short Export made from a selected portion of an Original.
